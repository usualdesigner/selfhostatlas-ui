## Install

```sh
npx shadcn@latest add @atlas/card-shell
```

## Usage

```tsx
import { CardShell } from "@/components/ui/card-shell"

<CardShell href="/self-host/immich">
  <h3 className="text-md font-semibold">Immich</h3>
  <p className="line-clamp-3 text-sm text-ink-3">Photo backup…</p>
  <span className="mt-auto text-sm text-accent group-hover:underline">Read guide →</span>
</CardShell>
```

## Props

| Prop | Type | Default | Notes |
|---|---|---|---|
| `href` | `string` | — |  |
| `children` | `ReactNode` | — | No nested links; CTAs are spans. |

## Accessibility

- One link per card; the heading inside is the link name.
- Depends on next/link; swap for <a> outside Next.
